IT 전담 인력 없는 기관을 위한
차세대 모니터링 솔루션

OWLmon은 학교 및 중소규모 공공기관의 IT 환경을 위해 설계된 경량 모니터링 솔루션입니다. 복잡한 설정 없이도 서버, 네트워크, 웹 서비스를 실시간으로 감시하고 지능형 알고리즘을 통해 장애를 사전에 예방합니다.

지능형 이상탐지 알고리즘

Z-Score 기반 통계적 탐지

최근 120개(1시간) 윈도우의 이동평균과 표준편차를 기반으로 현재 메트릭의 편차를 계산합니다. 특히 계절성(Seasonality) 보정을 위해 업무시간, 야간, 주말 데이터를 별도의 슬롯으로 관리합니다.

Z = (x - μ) / σ
  • Z ≥ 3.0 : Critical Alert
  • Z ≥ 2.5 : Warning Alert

선형회귀 디스크 고갈 예측

최소제곱법(Least Squares Method) 선형회귀를 사용하여 디스크 사용 추세를 분석합니다. 단순 현재 사용량이 아닌, 미래의 고갈 시점을 예측하여 알림을 발송합니다.

Condition

Predicts exhaustion within 7 days & R² (Confidence) ≥ 0.5

프로젝트 개선 제안 (Expert View)

1. 데이터 삽입 성능 개선 (PostgreSQL Copy)

현재 log_store.go의 Batch Insert 방식을 pgx.CopyFrom으로 전환하여 로그 데이터가 많아질 때의 CPU 부하를 50% 이상 절감 가능합니다.

2. 현대적 상태 관리 도입 (React Query)

프론트엔드의 useEffect 기반 폴링 로직을 TanStack Query로 전환하여 데이터 캐싱 및 네트워크 중복 요청을 최적화할 것을 권장합니다.

3. 로그 검색 고속화 (GIN Indexing)

대량의 로그 데이터 검색을 위해 PostgreSQL의 pg_trgm 확장 및 GIN 인덱스를 적용하여 텍스트 검색 속도를 10배 이상 향상시킬 수 있습니다.
