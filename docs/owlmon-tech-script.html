약 5분

구조도를 함께 보며 진행

아키텍처

"위 구조도처럼 3계층입니다. 에이전트가 메트릭을 OTLP로 보내면 Collector→Prometheus에 저장되고, Go 백엔드가 분석해 React 대시보드로 보여줍니다. 로그는 별도 HTTP로 PostgreSQL에 쌓입니다."

에이전트 · 경량

"에이전트는 Go + gopsutil, 목표 메모리 10MB·CPU 1% 이하. OTLP 표준이라 벤더 종속이 없고, 로그는 파일 tail, 디스크는 lsblk로 LVM 트리까지 수집합니다. 망분리를 위해 서버에서 새 바이너리를 자동 배포받는 self-update도 내장했습니다."

데이터 이원화

"백엔드는 Go + chi + JWT. 데이터는 성격별로 나눕니다 — 시계열 메트릭은 Prometheus, 알림·자산·로그·SSL·감사·AI 인사이트는 PostgreSQL."

이상탐지 · 핵심 차별점

"이상탐지는 외부 ML 라이브러리 의존성 zero, 순수 Go 구현입니다. Z-score+이동평균으로 계절성을 보정하고, 선형회귀로 디스크 포화 시점을 예측합니다. 경량 에이전트 철학을 서버까지 일관되게 가져간 겁니다."

알림 · 규칙 엔진

"알림은 디바운싱·중복제거·심각도 분류를 거쳐 폭주를 막고, 사용자 정의 규칙 엔진으로 조건을 직접 만들 수 있습니다. SSL·SNMP·DPM·합성 체크 모두 같은 알림 파이프라인을 탑니다."

LLM · 망분리 self-hosted

"LLM은 Ollama 엔진 + Gemma 4 12B 모델을 자체 호스팅합니다 — 둘 다 Apache 2.0/MIT라 상용 제약이 없습니다. 온디맨드(클릭하면 로그 설명)와 능동형(워커가 ERROR 로그를 Drain-lite로 템플릿 클러스터링→LLM→한국어 인사이트 저장) 두 갈래. 같은 패턴은 24시간 캐싱해 호출 비용을 아낍니다."

설계 철학 · 클로징

"전체를 관통하는 원칙 — 경량 · 표준(OTLP) 우선 · 4 Golden Signals · 망분리/보안(JWT·감사로그). 작게 설치하고, 표준을 따르고, 폐쇄망에서도 AI까지 돌린다 — 이게 OWLmon입니다."
