01 · DEFINITION
Zabbix란?
통합 인프라 모니터링 플랫폼
  • 서버 · 네트워크 장비 · 애플리케이션을 단일 플랫폼으로 모니터링하는 오픈소스
  • 에이전트 방식 + 에이전트리스(SNMP/IPMI/JMX) 모두 지원
  • 메트릭 수집 + 임계치 알림 + 시각화 + 자동 발견을 하나의 제품에서 제공
  • 라이선스: AGPL v3 (Zabbix 7.0 LTS, 2024.06부터 / 이전은 GPL v2)
Open Source AGPL v3 All-in-One Agent + Agentless Self-Hosted

04.1 · DATA COLLECTION
데이터 수집
📊

Data Collection

서버·네트워크·앱에서
다양한 프로토콜로
메트릭과 상태를 수집

🔹 수집 방식

  • Zabbix Agent — 호스트에 설치, Passive(서버→에이전트) / Active(에이전트→서버) 모드
  • SNMP — v1/v2c/v3, 스위치·라우터·UPS·프린터 등
  • IPMI — 하드웨어 센서 (전원·온도·팬)
  • JMX — Java 애플리케이션 (Tomcat, WAS)
  • HTTP/Web Scenario — REST API, 웹 페이지 응답시간
  • ODBC — DB 직접 쿼리 (MySQL, Oracle 등)

🔹 수집 주기

아이템별로 개별 설정 — 1s 부터 1d 까지 자유

🔹 데이터 타입

Numeric (float/integer), Character, Log, Text

04.2 · TRIGGERS
트리거 — 알림 조건 엔진
🚨

Triggers

수집된 데이터에 표현식을 적용해
이상 상태를 판단하고
알림을 발생시키는 규칙

🔹 기본 표현식

last(/Server/cpu.load) > 5

호스트의 최근 CPU load가 5 초과 시 발동

🔹 시간 함수

  • avg(/host/key, 5m) — 5분 평균
  • min/max(/host/key, 1h) — 1시간 최소/최대
  • forecast(/host/key, 1h, 30m) — 30분 후 예측

🔹 복합 조건 + 심각도

AND/OR 조합 + 6단계 심각도 (Information ~ Disaster)

의존성: "스위치 다운" 트리거가 발동 중이면 그 아래 서버 트리거는 무시 → 알림 폭주 방지

04.3 · TEMPLATES
템플릿 — 모니터링 정책의 재사용 단위
📋

Templates

Items + Triggers + Graphs +
Discovery 룰을 묶은
재사용 가능한 모니터링 패키지

🔹 구조

"Linux by Zabbix Agent" 템플릿 하나에 → CPU·메모리·디스크·네트워크 아이템 수십 개 + 임계치 트리거 + 그래프가 모두 포함

🔹 상속

Linux OS (기본) └─ Linux Production (운영용 임계치 강화) └─ web-server-01 (개별 호스트)

하위 호스트가 상위 정책을 자동 상속

🔹 공식 템플릿 1000+

Linux, Windows, Cisco, MikroTik, MySQL, PostgreSQL, Redis, Nginx, Docker, Kubernetes, AWS, Azure 등 — 설치 직후 바로 사용

04.4 · DISCOVERY
자동 발견 — 수동 등록 노가다 제거
🔍

Discovery

새 장비·새 디스크·새 인터페이스를
자동으로 발견하고
모니터링 등록까지 자동화

🔹 Network Discovery

IP 범위(예: 192.168.1.1-254)를 주기적으로 스캔 → ping/SNMP/포트 응답 기반으로 신규 호스트 자동 등록

🔹 LLD (Low-Level Discovery)

호스트 내부의 동적 항목을 발견:

  • 디스크 파티션 (sda1, sda2, nvme0n1p1...)
  • 네트워크 인터페이스 (eth0, ens33, wlan0...)
  • Docker 컨테이너, K8s Pod, DB 테이블 등

→ 새 디스크 꽂으면 자동으로 모니터링 시작

🔹 Active Agent Auto-registration

에이전트가 먼저 서버에 접속(능동) → 서버가 자동으로 호스트 등록 + 템플릿 적용. 대규모 서버 프로비저닝에 필수

04.5 · VISUALIZATION
시각화 — 데이터를 그림으로
📈

Visualization

수집한 메트릭을
대시보드·맵·그래프로
한눈에 파악

🔹 Dashboards (7.0+ 강화)

위젯 기반 드래그&드롭 — Graph, Problem, Top Hosts, Map, URL, SLA 등 30+ 위젯 조합 가능

🔹 Network Maps

인프라 토폴로지를 그래픽으로 시각화 — 장비 아이콘 + 연결선 + 실시간 상태 색상

🔹 Graphs

아이템 단위 시계열 그래프, 사용자 정의 그래프(여러 아이템 조합), 스택형/선형/원형 차트

🔹 Grafana 연동

Zabbix 공식 Grafana 플러그인 — 더 예쁜 대시보드가 필요하면 Grafana로 시각화만 분리

05 · ANALYSIS
강점과 약점

✅ 강점

  • 올인원 — 별도 제품 조합 불요
  • 풍부한 공식 템플릿 (1000+)
  • 대규모 확장성 (Proxy 구조)
  • 25년 검증된 안정성
  • 무료 (AGPL v3)
  • 강력한 알림 엔진

⚠️ 약점

  • 설치/설정 복잡 (며칠 단위)
  • UI 구식 (PHP 기반)
  • 학습 곡선 가파름
  • 한국어 자료 부족
  • 클라우드 네이티브 약함
  • DB 부담 큼 (수만 host 시)
