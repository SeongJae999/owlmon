1프로젝트 비전

"IT 전담 인력이 없는 학교/공공기관도 5분 안에 설치해서 즉시 가치를 얻는, 단정하고 신뢰감 있는 모니터링 도구"

핵심 정체성

  • 타겟: 한국 학교 · 공공기관 (IT 비전담 환경)
  • 경쟁상대: Zabbix (복잡함) / Datadog (영문/비싸다)
  • 차별화: 한국어 위주 UI · 단순 설치 · 단정한 다크 톤 · 알림 디바운싱 · 이상탐지 + 자체 LLM 로드맵

사업 모델

  • 1단계 — 납품형 (구축비 500만~수천만 원)
  • 2단계 — SaaS 구독형 (서버 10대 기준 월 5만 원)
  • 전략 — Sentry 모델 (설치 간편 → 즉시 가치 → 무료 티어 → 유료 전환)

3시스템 아키텍처

  • 외부 API 의존 zero — 망분리 환경 대응 가능

7디자인 철학

핵심 원칙

  • 실용성 우선 — 모니터링은 매일 보는 도구, 장식보다 정보가 우선
  • 한국어 위주 — 학교 IT 담당자에게 영문 대문자 라벨은 인지 부담
  • 다크 테마 — 모니터링 도구 표준(Datadog/Grafana/Linear)이며 장시간 사용 피로 ↓
  • 정보 밀도 — 학교 IT는 한 화면에 가능한 많은 호스트를 봐야 함
  • 장식 절제 — glow/animate-bounce 같은 마케팅 효과는 트레이드오프 없이 제거

10확장 방향 (도청급)

현재는 학교 단위에 최적화되어 있지만, 미래 도청/광역 자치단체 진입 시 어떤 부분이 어떻게 진화해야 하는지 미리 점검합니다.
